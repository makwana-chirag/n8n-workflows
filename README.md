# n8n Workflows

Collection of my n8n automations for personal use.

## 🔧 Workflows

### Social Media

- `linkedin-post-scheduler.json` - Auto-post to LinkedIn
- An automated end-to-end pipeline that triggers AI post generation, formats content for specific social platforms, and publishes directly to LinkedIn using a multi-step approval gate.

## 🚀 Setup

1. Clone this repo
2. Run `docker-compose up -d`
3. Import workflows from `n8n-workflows/`
4. Reconnect credentials

## 📝 Adding New Workflows

1. Create workflow in n8n
2. Export to `n8n-workflows/`
3. Commit and push
